1. React Application Architecture
Your first task is to build the foundation. Since you are using React, you need a structure that supports scaling for Milestones 2 and 3.

Project Initialization: Set up the project using a modern build tool like Vite. Immediately integrate ESLint and Prettier to enforce the "high-quality documentation" and "consistent code style" required for Artemis.

Routing Setup: Use react-router-dom to define the primary paths:

/ (Home/Landing)

/login & /register

/onboarding (The multi-step process)

/planner (The main dashboard for MS1)

Layout Skeleton: Create a MainLayout wrapper component.

Navbar: Include links to the Planner and Profile, along with a Logout button.

Sidebar/Nav: A simple skeleton to handle navigation between different plan variants later.

Content Area: Use an <Outlet /> to render the specific page content.

2. Three-Step Onboarding UI
This is a critical flow for capturing user data. You should manage the state of this form carefully (e.g., using useState or a form library like react-hook-form).

Step 1: Profile Information: Build a form for the user to select their Major and Year of Study. Use controlled components to ensure data is captured accurately.

Step 2: Completed Modules (Search & Chips): * Implement a search input that filters through the module list (fetched from the backend/NUSMods).

When a user selects a module, render it as a "Chip" component with a "Delete" icon so they can manage their completed list.

Step 3: Academic Goals: A final section where users can input their interests or specific goals for the AI to consider.

Submission Logic: On the final step, consolidate all data into a single JSON object to be sent to your profile API.

3. Backend API Integration
You are the bridge between the UI and the server. For MS1, you must ensure the "Technical Proof of Concept" is fully integrated.

Authentication (Auth): Create services to handle login and registration. Ensure you store the user's session (e.g., JWT) in a way that allows the frontend to stay authenticated across refreshes.

Profile Persistence: Connect the Onboarding UI to the POST /profile endpoint. This must successfully save the student's major and completed modules into the PostgreSQL database.

Recommendation Trigger: Set up the logic to call the recommendation API. This will send the user's profile data to the backend and wait for the AI-generated response.

4. Feature Display: Recommendations & Prereqs
Once the data is fetched, you need to present it clearly to the user.

Module Recommendation Display
Create a Card Component that displays:

Module Code and Name (e.g., CS2103T Software Engineering).

The "Why": A text block showing the AI-generated explanation for the recommendation.

Action Button: A button to "Add to Plan" (even if the full planner functionality comes in MS2).
